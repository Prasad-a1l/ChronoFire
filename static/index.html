ChronoFire Scientific Methodology & Mathematical Framework

1. The Multi-Sensor Fracture Problem

MODIS (Terra/Aqua, 1 km) and VIIRS (Suomi-NPP/NOAA-20/NOAA-21, 375 m) cannot be directly compared. With a 7x finer pixel footprint area, VIIRS detects smaller, lower-intensity smoldering fires ($FRP \ge 0.5\text{ MW}$ vs MODIS $\ge 5\text{--}10\text{ MW}$), causing a fictitious 3x to 5x detection surge starting in 2012.

2. Spatio-Temporal Event Clustering (ST-DBSCAN)

Clusters discrete satellite pixel hotspots into unified physical fire complexes using great-circle haversine distance ($d \le 1.8\text{--}2.4\text{ km}$) and a 24-hour temporal window. This eliminates pixel-size artifacts by tracking real fire front perimeters.

3. Biome-Stratified Power-Law Transfer Functions

Harmonizes the overlapping co-observation record (2012-2026) using non-linear quantile mapping: H* = alpha_b * [H_VIIRS]^(beta_b) Calibrated across 7 ecological biomes: Tropical Forest ($\alpha=0.238, \beta=0.945$), Mediterranean Scrub ($\alpha=0.357, \beta=0.978$), Cropland ($\alpha=0.208, \beta=0.930$).

4. NASA Terra Post-2020 Orbital Drift Compensation

Since February 2020, NASA ceased inclination maneuvers for Terra. Equator crossing drifted from 10:30 AM to ~09:00 AM MLST. ChronoFire compensates for diurnal combustion depression using $D_t = 1.0 + 0.042 \times \max(0, \text{Year} - 2020)$.

5. Climatology Reference & Standardized Anomaly (Z-Score)

Baseline normals derived from 2001-2020 multi-year observations: Z = (H* - Climatology_Mean) / Climatology_Std Categorized from Suppressed ($Z < -1.5\sigma$) to Megafire Crisis ($Z \ge +2.0\sigma$).
